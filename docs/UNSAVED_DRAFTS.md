# Защита несохранённых определений

Продолжение Web #13 (`ddd5368`). Контракт Core не меняется; live CI по-прежнему
использует Core #35 + точный delta #33 и изолированные PostgreSQL/MQTT fixtures.

Существующие маршруты React Router переведены с BrowserRouter/Routes на
createBrowserRouter/RouterProvider для штатного useBlocker. Экраны, Query cache,
авторизация и API остаются прежними. Один DraftGuard суммирует флаги всех форм;
значения форм не передаются реестру и остаются в памяти компонентов.

Незавершённое создание (в том числе свёрнутое), изменённое имя и выполняющийся
запрос блокируют переходы между маршрутами, включая Back/Forward. Native modal
dialog предлагает «Остаться» или «Отменить изменения и продолжить». Начальный
фокус — на «Остаться»; Escape оставляет на странице; фон недоступен при открытом
модальном окне. Отмена имени и удаление черновика также требуют подтверждения.
Пустая/неизменённая форма не мешает навигации. Явно подтверждённый уход удаляет
черновик; возврат открывает свежие данные, не восстанавливая его.

При 409, сетевой ошибке и повторной попытке защита остаётся активной. Обновление
списка не удаляет черновик. После подтверждённого сохранения защита этой формы
снимается; другие несохранённые формы продолжают блокировать уход. Если запрос
завершается успешно во время открытого предупреждения, заблокированный переход
отменяется: приложение не уходит неожиданно. Уход во время запроса не отменяет
уже принятую Core запись — предупреждение прямо просит проверить данные позже.

Для reload/закрытия вкладки используется beforeunload только пока есть изменения
или запрос. Текст и кнопки такого предупреждения задаёт браузер. Браузеры могут
не показывать его без взаимодействия пользователя; закрытие мобильного процесса,
сбой, истечение/отзыв сеанса и принудительное удаление рабочего контекста не
гарантируют сохранность памяти. Защита не задерживает инвалидирование авторизации.
После принятого ухода восстановить черновик нельзя. Local/session storage,
IndexedDB, URL, cookies и сервер для хранения черновиков не используются.

Проверки: unit-тесты реестра нескольких форм, beforeunload, Escape/отмена,
выполняющийся запрос и снятие блокировки; browser-тесты ссылок, Back/Forward,
отменённой перезагрузки, клавиатуры, axe, пяти размеров экрана, 409/503/retry и
подтверждённого сохранения. Native dialog в jsdom заменён только тестовой
заглушкой; настоящий Chromium проверяет фокус и клавиатуру. Live CI проверяет
защиту после настоящих 409 Core для сцен и автоматизаций без новых MQTT-команд.

Запуск: npm ci; npm run typecheck; npm run lint; npm test; npm run build;
npm run test:e2e; npm run test:e2e:core. Изолированный live runner описан в
LIVE_SOFTWARE_CI.md. Никакие production, секреты, привилегии и физические
устройства не используются.

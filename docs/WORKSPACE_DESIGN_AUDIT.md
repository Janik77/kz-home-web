## Что было опубликовано

Все merged PR #1–#9 входят в main 809266f и выбранную базу. #1 — foundation; #2 — refinement; #3/#4 — Core read/live; #5 — premium redesign; #6–#9 — права, подтверждения и защита гонок управления. Open #10–#14 последовательно входят в fac23c2: русский workspace, live fixture, определения, revisions, черновики. #15 только создаёт интеграционную ветку на том же commit. Ни одна опубликованная feature-ветка не потеряна при этой сборке.

Разное оформление объясняется самим PR #5 (4670700): signature.css содержал комментарий «Signature Home is deliberately scoped: other screens retain the v0.5 layout». AppShell применял signature-shell только к `/`. Между #5 и #15 signature.css не менялся; главная не была заново нарисована интеграционным PR. #10 сохранил английские fixture-названия вне Home, где использовался отдельный словарь. Поэтому внешний вид и язык менялись при переходах.

В доступном checkout и его родительском workspace нет .idea или предоставленной Local History. История PyCharm находится на компьютере владельца и не является Git-историей. Нельзя утверждать, что незакоммиченные пользовательские изменения были восстановлены или сравнивались. Удалённые ранее непубличные ветки также не доказаны этим аудитом. Ничего из найденных веток/PR не удаляется.

## Изменения этой части

Сохранены React/TypeScript/Vite, маршруты, data adapters, controls, draft guard и CAS. Убраны отдельные shell-токены Home, все страницы используют общую навигацию, палитру, масштаб и карточки. Home сохраняет интерьерную композицию. В demo локализованы fixture-названия без изменения ID/команд/числа устройств. Примеры правил отключены, события явно иллюстративны. Баннер demo виден на каждом экране. Реальные Core данные не переименовываются. Диагностика вынесена в раскрываемые разделы; предупреждения/ошибки и подтверждения не скрываются.

scripts/capture.mjs сохраняет Home, Rooms, Room, Devices, Scenes, Rules, Events, Settings и настоящий login в обеих темах при 1440/390/320 px. Before/after — frontend demo, не настоящий дом. Core browser и live suites сохраняются отдельно. Новый Web SHA не принимается старым Core launcher, закреплённым на fac23c2: для нового UI используется существующий live runner с Core #36, а согласование launcher — отдельный шаг, без ослабления pin.
